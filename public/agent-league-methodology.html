Overview

The Agent League OVR (Overall Rating) system evaluates agent performance on a 0-99 scale using nine weighted attributes. Inspired by sports analytics (EA Sports Madden, FIFA), each agent receives a composite rating that reflects their daily contribution across production, speed, efficiency, and reliability metrics.

Purpose: Provide a single, transparent number that captures total agent value. Not a disciplinary tool — a development and recognition system. High OVR = high impact. Low OVR = coaching opportunity.

7Talk Time (TLK)8%Twilio CDR / YticaHigher = BetterEngagement — meaningful conversations, not rushed calls
8Wrap-Up (WRP)7%Ytica Avg Wrap Up TimeLower = BetterEfficiency — quick post-call work means faster back to queue
9Decline Rate (DCL)6%Twilio TaskRouterLower = BetterCommitment — not cherry-picking or dodging calls
Weight rationale: Conversions + Conv% = 33% because revenue generation is the core mission. Speed + Volume = 24% because availability drives client satisfaction. Conv/Hr + Pickup + Decline = 28% because productivity and reliability are what make an agent dependable. Talk Time + Wrap-Up = 15% because engagement quality and efficiency are supporting factors, not primary drivers.
Normalization Curves (0-97 Effective Scale)

Each raw metric is converted to a 0-97 sub-rating. 99 is unreachable by formula — it exists as a theoretical ceiling to prevent clustering at the top. The curves use diminishing returns: going from 85 to 90 is much harder than going from 50 to 55. Volume and Talk Time are normalized by scheduled hours to prevent rewarding longer shifts over efficiency.

Why 97 not 99? If too many agents cluster at 99, the rating loses meaning. By capping at 97 and using steep diminishing returns near the top, the gap between 90 and 95 represents genuine excellence. Only one agent at a time should be near 97 in any category.

Known Limitations
  • Historical pickup/decline rates are not stored. Baseline pickup rate is neutral (50) until historical data collection begins.
  • March 2026 conversion counts are not yet backfilled. Baseline conversion sub-ratings default to 0 for March, making trend arrows show "up" for all agents.
  • Blended agents (Wendy, Sara) appear in both JC and MSC views. Their OVR reflects total volume across both brands.
  • Outbound agents (William, Joseph) are not currently rated — the system is designed for inbound agents.

Known Methodology Weaknesses

This rating system is v1.1. We are transparent about its limitations and actively improving:

  • No call quality metric. The system measures speed, volume, and outcomes — but not how well an agent handles a difficult call. A future "Quality Score" from call reviews or client satisfaction surveys would add a 10th attribute.
  • Conversion attribution is coarse. An agent who warms a lead across 3 calls gets no credit if a different agent logs the final conversion. Multi-touch attribution would be more fair.
  • Decline rate data is sparse. TaskRouter doesn't always populate this. Many agents show null, which defaults to 65 (benefit of doubt). As data improves, this default will tighten.
  • Historical baselines are thin. The accumulator currently only has March 2026 partial data. Trend arrows will become meaningful as months accumulate.
  • Weekend/off-peak hours aren't weighted differently. A Sunday shift with fewer calls isn't the same competitive environment as a Monday. Future versions may apply day-of-week normalization.
  • Blended agents get a volume advantage. Wendy and Sara handle both JC and MSC calls — their total volume is higher than single-brand agents, even normalized by hours. Brand-level splitting would fix this.
