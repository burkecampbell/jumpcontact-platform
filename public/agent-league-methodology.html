Overview

The Agent League OVR (Overall Rating) system evaluates agent performance on a 0-99 scale using nine weighted attributes. Inspired by sports analytics (EA Sports Madden, FIFA), each agent receives a composite rating that reflects their daily contribution across production, speed, efficiency, and reliability metrics.

Purpose: Provide a single, transparent number that captures total agent value. Not a disciplinary tool — a development and recognition system. High OVR = high impact. Low OVR = coaching opportunity.
The Nine Attributes
# Attribute Weight Source Direction Why It Matters
1Conversions (CNV)18%Conversions SheetHigher = BetterDirect revenue generation — booked appointments
2Conv % (C%)15%Conversions / CallsHigher = BetterEfficiency — converting opportunities, not just volume
3Volume (VOL)12%Twilio CDR / YticaHigher = BetterAvailability and throughput — handling the queue
4Speed (SPD)12%Ytica Avg Speed to AnswerLower = BetterFirst impression — callers wait less, fewer abandonments
5Conv/Hr (CPH)12%Conversions / Scheduled HoursHigher = BetterProductivity per hour — normalizes for different shift lengths
6Pickup Rate (PKP)10%Twilio TaskRouterHigher = BetterReliability — answering when calls come in
7Talk Time (TLK)8%Twilio CDR / YticaHigher = BetterEngagement — meaningful conversations, not rushed calls
8Wrap-Up (WRP)7%Ytica Avg Wrap Up TimeLower = BetterEfficiency — quick post-call work means faster back to queue
9Decline Rate (DCL)6%Twilio TaskRouterLower = BetterCommitment — not cherry-picking or dodging calls
Weight rationale: Conversions + Conv% = 33% because revenue generation is the core mission. Speed + Volume = 24% because availability drives client satisfaction. Conv/Hr + Pickup + Decline = 28% because productivity and reliability are what make an agent dependable. Talk Time + Wrap-Up = 15% because engagement quality and efficiency are supporting factors, not primary drivers.
Normalization Curves (0-99 Scale)

Each raw metric is converted to a 0-99 sub-rating using specific curves designed to reward excellence without punishing normal performance. The curves are non-linear — the jump from "good" to "great" is harder than from "average" to "good."

OVR Calculation
OVR = round( CNV × 0.18 + // Conversions sub-rating C% × 0.15 + // Conv % sub-rating VOL × 0.12 + // Volume sub-rating SPD × 0.12 + // Speed sub-rating CPH × 0.12 + // Conv/Hr sub-rating PKP × 0.10 + // Pickup Rate sub-rating TLK × 0.08 + // Talk Time sub-rating WRP × 0.07 + // Wrap-Up sub-rating DCL × 0.06 // Decline Rate sub-rating )

Time Horizons

Trend Arrows: The ▲ and ▼ indicators compare the current horizon's OVR against the baseline (previous month). A difference of >2 points triggers an arrow. This shows momentum — is the agent improving or declining?

Known Limitations
  • Historical pickup/decline rates are not stored. Baseline pickup rate is neutral (50) until historical data collection begins.
  • March 2026 conversion counts are not yet backfilled. Baseline conversion sub-ratings default to 0 for March, making trend arrows show "up" for all agents.
  • Blended agents (Wendy, Sara) appear in both JC and MSC views. Their OVR reflects total volume across both brands.
  • Outbound agents (William, Joseph) are not currently rated — the system is designed for inbound agents.
